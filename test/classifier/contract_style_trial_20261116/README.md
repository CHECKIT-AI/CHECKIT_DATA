# 신규 계약서 형식 분류 시험

가상 사업장 12곳의 1페이지 근로계약서를 새로 작성했다. 각 PDF는 조항 10개로 구성하며, 총 120개 조항 중 단일 라벨 60개·두 라벨 60개다. 이름·사업장·문구는 모두 합성이며 실제 체결 계약서가 아니다. 정답은 모델 예측을 보기 전에 `gold.jsonl`에 고정했지만 독립 전문가 검수 전 `PROVISIONAL_UNREVIEWED` 상태다.

`generate.py`는 PDF와 정답을 만들고, 기존 학습·평가 문장과 완전히 같은 문장이 없는지 검사한다. `manifest.json`에는 정답과 PDF별 SHA-256을 기록한다. 평가에서는 머리말과 서명부를 제외한 정답 조항 본문을 분류 모델에 직접 입력한다. OCR·조항 분리·RAG·법률 판단은 이 시험의 범위가 아니다.

성능 비교는 배포 모델, 2차 모델, 3차 모델을 같은 120개에 적용한다. 후보로 볼 최소 기준은 **전체 정확 일치가 배포 모델보다 6건 이상 증가**, **두 라벨 60개에서 9건 이상 증가**, **단일 라벨 60개에서 감소하지 않음**이다. 기존 core 446개와 고정 60개에서도 큰 하락이 없어야 한다. 이 기준을 통과해도 동일 작성자의 합성 문서이므로 실제 계약서 배포 검증을 대체하지 않는다.
