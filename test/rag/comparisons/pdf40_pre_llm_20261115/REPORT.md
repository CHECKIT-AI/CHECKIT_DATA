# 40개 합성 PDF 조항의 LLM 직전 평가 (2026-11-15)

## 입력과 정답 기준

- PDF 40개에서 추출한 본문 조항 478개가 원본 조항 478개와 1:1로 대응했다. 머리말·서명부 80개는 제외했다.
- 40개 마지막 조항에 붙어 있던 합성 PDF 바닥글을 평가 입력에서 제거했다. 실제 검색 질의는 남은 **조항 원문**이며 쟁점 설명, 문제 코드, 정답 조문은 질의에 넣지 않았다.
- `provisional_clause_relevance.jsonl`은 67개 문제 조항의 기존 1차 검수와 정상 조항의 범주별 원문 표본을 바탕으로 411개 정상 조항에 공통 규칙을 적용한 **잠정 엔지니어링 정답**이다. 478개를 법률 전문가가 개별 검수한 표는 아니다. 직접 근거 353개, 보조 근거만 있는 조항 63개, 현재 corpus에 대상이 없는 조항 62개다. 직접 근거가 있는 353개만 주 검색 지표의 분모로 썼다.
- 원본 계약 체결일은 2026-02-20이고 corpus의 근로기준법 판본은 2026-10-08이다. 날짜가 필요한 후보 규칙 시험에서만 2026-11-15를 사용했다. 이 결과는 실제 체결일의 법률 적용 판단이 아니다.

## 변경 내용과 남은 병목

기존 `search_clause`는 이 검색 방식에서 예측 라벨을 사용하지 않았다. 지금은 상위 후보 중 라벨에 맞는 법령을 먼저 놓되, 같은 그룹 안에서는 원래 검색 순서를 유지한다. dense 거리와 BM25 순위의 점수 단위를 섞지 않는다. 가산수당 제56조를 `임금` 라벨에 추가해 문제 조항의 1위 역행 3건을 막았다. 결과에는 `retrieval_policy=labels_stable_priority_v2`, 각 hit에는 `base_rank`와 `matched_labels`가 남는다.

남은 상위 5개 실패 70건 중 50건은 현재 후보풀에도 직접 근거가 없다. 특히 근무장소 10/42, 업무내용 15/40만 직접 근거가 상위 5개에 있다. 계약기간은 20/22가 상위 5개에 들어가지만 1위는 0/22다. 연차는 36/36이 상위 5개에 있으나 1위는 0/36이다. 다음 개선은 이 주제의 **후보 생성**과 상위 후보 내 **원문 관련성 순위**를 별도로 검증해야 한다.
