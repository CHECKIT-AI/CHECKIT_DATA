## 질의와 후보 생성

- 누락 항목: `issues.jsonl`의 문제 설명에서 `누락`을 떼고 `근로계약서에서 {항목}을 서면으로 명시하고 근로자에게 교부해야 하는 법적 의무`로 검색했다. 조항 원문은 없는 항목이다.
- 위법·불공정 문구: `{원래 조항 문구} 검토 쟁점: {issues.reason의 첫 문장}. 관련 법령`으로 검색했다.
- 정답 조문 이름·번호·ID는 **질의와 재정렬 입력에 넣지 않았다**. 하지만 `issues.reason`은 벤치마크 작성자가 부여한 문제 설명이다. 실제 서비스에서 이를 사용하려면 상류 탐지가 해당 쟁점을 맞혀야 한다. 이 시험은 그 조건을 이미 아는 **oracle 쟁점 실험**이며 종단간 성능이 아니다.
- 단일 질의 검색은 현재 `dense_bm25_top5`를 그대로 사용했다. RRF 시험은 원문과 쟁점 질의의 상위 10개를 동일 가중치, `rrf_k=60`으로 결합했다. 재정렬 시험은 쟁점 질의의 dense 후보(최대 21개)와 BM25 후보(상위 10개)의 중복 제거 합집합 전체(질의당 22~31개)를 `BAAI/bge-reranker-v2-m3`의 고정 revision으로 채점해 상위 5개를 반환했다. 모델 점수는 확률이 아니다.
