# 추가 자료 검색 개발셋 v001

2026-10-28 추가 범위 검색 실행 전에 원문을 읽고 42개 질의를 고정했다. 14개 주제마다 키워드·사용자 질문·가상 상황 설명이 각 1개다. 각 레코드의 대표 정답 ID·원문 근거 발췌·출처를 보존한다.

상태는 DRAFT이며 전문가·독립 검수 전이다. 실제 계약서나 실제 사용자 질의가 아니고, 이전 API 확인과 일부 주제가 겹치므로 미사용 최종 평가셋이 아니다. 질문의 어휘는 원문과 겹칠 수 있다. 법률 판단 정답이나 모든 관련 조문을 망라한 정답으로 사용하지 않는다. 세 가지 표현은 서로 연관돼 독립 표본으로 해석하지 않는다.

추가된 청크 54개 중 대표 목표 14개를 표본으로 선택했다. 시행규칙의 행정 절차 질문도 포함하므로 계약서 문장만으로 이뤄진 평가셋이 아니다. 검색 후 정답이나 질의를 바꾸지 않았으며 개선 실험에는 이 버전을 고정해 사용한다.
