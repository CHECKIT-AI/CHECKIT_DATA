# 멀티라벨 보강 1차 학습 실험 (2026-11-15)

## 데이터와 학습

- 두 주제가 한 조항에 담긴 합성 문장 736개를 새로 작성·생성했다. 23개 라벨 조합별로 학습 24개, 개발 4개, 테스트 4개이며 총 **학습 552 / 개발 92 / 테스트 92**개다.
- 분할별 문구 재료를 분리했고, 기존 core 분할 및 고정 60개 평가셋과 완전히 일치하는 문장은 없다. 생성 정답은 작성자 잠정 라벨이며 독립 검수 전이다.
- 기존 core 3,470개와 합성 단일 라벨 240개에 새 552개를 더해 **4,262개**로 KLUE-RoBERTa 기반 모델을 3 epoch 학습했다. 멀티라벨 개발셋 Macro F1로 선택한 체크포인트는 **2 epoch**다. 기존 BE 모델은 교체하지 않았다.
- 생성 문장은 두 개의 주제별 문장을 마침표나 세미콜론으로 연결한 형태가 많다. 한 문장 안에서 주제가 섞이는 실제 조항의 모든 표현을 대표하지 않는다.

## 현재 배포 모델과 새 체크포인트 비교

| 평가셋 | 기존 exact match | 새 모델 exact match | 기존 Micro F1 | 새 모델 Micro F1 |
| --- | ---: | ---: | ---: | ---: |
| 새 멀티라벨 개발 92개 | 10/92 (10.9%) | 75/92 (81.5%) | 0.657 | 0.947 |
| 새 멀티라벨 테스트 92개 | 10/92 (10.9%) | 86/92 (93.5%) | 0.655 | 0.984 |

| 기존 core 테스트 446개 | 374/446 (83.9%) | 363/446 (81.4%) | 0.860 | 0.840 |
| 기존 합성 PDF 조항 478개 | 461/478 (96.4%) | 405/478 (84.7%) | 0.979 | 0.905 |

고정 60개 중 두 라벨 10개는 **0→9/10**으로 좋아졌지만, 기존 PDF의 두 라벨 16개는 **0→0/16**이다. PDF 단일 라벨 조항도 **461/462→405/462**로 하락했다. 기존 core 테스트의 두 라벨 일치는 **3/16→5/16**으로 소폭 올랐으나 전체는 11건 줄었다.

## 판단

새 모델은 생성기와 유사한 개발·테스트 문장에 매우 잘 맞는다. 독립적으로 작성한 고정 60개에도 개선이 있으나, 기존 PDF에서 큰 역행이 있어 **배포 후보로 채택하지 않았다**. PDF 정답은 잠정 라벨이고 조항 문구가 반복되므로 96.4%도 운영 정확도가 아니지만, 같은 평가셋에서 완전 일치 56건 순감소는 무시할 수 없다. 기존 core 테스트에서도 근로시간 F1은 0.932→0.866, 계약기간 0.931→0.873, 손해배상·위약금 0.632→0.556으로 하락했다.

다음 실험은 기존 배포 체크포인트에서 낮은 학습률로 소폭 재학습하고, 한 문장에 두 주제가 섞인 문구를 별도 학습 데이터로 보강해야 한다. 고정 60개와 PDF 40개는 학습에 넣지 않는다. 더 이상 이 두 평가셋을 반복 조정 기준으로 사용하면 과적합 위험이 있으므로, 모델 선택은 개발셋에서 하고 두 셋은 최종 확인에만 사용한다.
