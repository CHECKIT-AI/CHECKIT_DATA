## PDF 정답 라벨 재검토 필요

PDF의 두 라벨 16건은 5종 문구의 반복이다. 7건은 잠정 정답의 두 번째 라벨이 문구와 맞지 않아 보인다: 손해 전액 배상 4건에 계약 종료, 임금 공제 2건에 근로시간, 수습 후 본채용 거절 1건에 기타 근로조건이 붙어 있다. 나머지 퇴사 위약금 6건과 연장·야간·휴일근로 수당 3건은 두 주제가 모두 드러난다. 원본 정답 파일은 수정하지 않았으며, 아래 민감도 분석만으로 검수된 정답 기준 성능을 주장할 수 없다.

`CheckIt_Eval_Benchmark_v1.0.1`을 별도 생성해 위 7건의 조항·문제·검색 질의 라벨과 세부 카테고리를 일치시켰다. v1.0.0은 보존했다. 같은 모델을 v1.0.1 기준으로 다시 평가한 결과 PDF 478건 exact match는 배포 모델 **461→465건**, 2차 모델 **455→461건**이었다. 수정 기준에서 두 라벨 조항은 12건이며 exact match는 각각 **0/12, 2/12**다. 손해배상 4건은 두 모델 모두 일치하고, 임금 공제 2건은 2차 모델만 일치한다. 수습 조항은 두 모델 모두 `계약기간`만 예측해 수정 기준에서도 불일치한다. 수습 조항을 단일 `계약기간`으로 본다면 각각 466건, 462건이다. 어느 가정에서도 PDF의 2차 모델 성능 저하는 해소되지 않는다. 이 값은 **잠정 라벨 기준 평가**이며 전문가가 확정한 정답 기준 성능이 아니다.

v1.0.1 생성기는 업무 중 손해 배상에 붙은 `TERMINATION`, 임금 공제에 붙은 `WORK_HOURS`를 제거하고 수습 중 본채용 거절에 `TERMINATION`을 추가한다. 40개 PDF·478개 조항·96개 문제의 무결성 검증을 통과했고, v1.0.0과 비교해 조항·문제·검색 질의 정답은 동일한 7건만 바뀌었다.

두 재평가 결과가 참조한 v1.0.1 `ground_truth/clauses.jsonl`의 SHA-256은 `eb1fa9984ccabf6162e6802a210ade58c99135f75d4fb567a970f994024a0def`다. 40개 PDF의 추출 텍스트는 v1.0.0과 동일하지만 재생성된 파일의 바이너리 해시는 다르다.

## 판단과 한계

2차 모델은 새로운 통합형 문구와 고정 60개에서 개선됐고 core 테스트도 유지했다. 최신 v1.0.3 PDF 기준으로는 **1건 순증가**했지만, 두 주제가 명시된 퇴사 위약금 6건과 시간외 수당 3건은 여전히 완전 일치하지 않는다. 반복 합성 문구와 잠정 라벨에서 1건 차이로 배포를 결정하기 어려워 **배포 모델은 교체하지 않았다**.

새 개발·테스트도 작성자 합성 문구와 잠정 라벨이다. 고정 60개와 PDF 40개는 모델 선택에 사용하지 않았지만 이미 여러 실험에서 결과를 확인했으므로 독립 최종 테스트의 역할은 제한된다. 배포 판단에는 라벨 검수와 별도의 실제 문구 평가가 필요하다.
