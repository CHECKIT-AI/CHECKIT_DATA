# 멀티라벨 실계약형 보강 3차 실험 (2026-11-16)

## 기존 데이터와 추가량

기존 학습 분할 3,710개는 단일 라벨 3,475개, 두 라벨 228개, 세 라벨 7개다. 즉 **멀티라벨 235개(6.3%)**가 이미 있었다. 1차 멀티라벨 552개와 2차 통합형 150개를 더한 2차 모델의 학습량은 4,412개였다.

이번에는 `퇴사+위약금`, `임금+근로시간`, `수습기간+종료`, `퇴직+임금`, `임금+손해배상`, `퇴직+휴가` 여섯 조합에 대해 **576개**를 추가 생성했다. 학습 384개, 개발 96개, 테스트 96개다. 총 72개 문장 틀에 8개 직무 변형을 적용했고, 문장 틀은 분할 간 겹치지 않는다. 기존 분할·고정 60개·PDF 조항과 완전히 같은 문장은 없으며 입력 파일의 SHA-256을 manifest에 기록했다. 새 데이터의 라벨은 작성자 잠정 정답이며 독립 검수 전이다.

3차 학습에는 기존 3,710개 + 1차 552개 + 2차 150개 + 새 384개, 총 **4,796개**를 사용했다. 이 중 멀티라벨은 **1,321개(27.5%)**다. 현재 배포 모델의 고정 revision `1accf527c060396c5801b044e2cebf8bedb5ac12`에서 1 epoch 추가 학습했고, 학습률 5e-6과 3e-6을 각각 시험했다. 배치 크기는 16, 예측 기준값은 라벨별 0.5다.

PDF 정답은 `CheckIt_Eval_Benchmark_v1.0.3`을 사용한다. v1.0.2에서 `근로시간과 임금을 동의 없이 변경`하는 UT01 조항 4건에 명시된 `임금` 라벨을 추가했다. 생성된 조항·문제·검색 질의에서 이 4건만 바뀌었고 PDF 40개의 추출 텍스트는 동일하다. 무결성 검증을 통과했다. v1.0.3 정답 SHA-256은 `bfb6422661abb4ebf62513af33fa012d2660460a49fa5eaf4211513917141608`이다.

## 해석 한계

- 새 데이터는 PDF 오답을 본 뒤 설계했다. PDF와 완전히 같은 문장은 없지만 주제와 표현이 가깝다. UT01 정답 4건도 3차 모델 예측을 살펴본 뒤 수정했다. 따라서 PDF 멀티라벨 17/17은 독립 최종 테스트 성능이 아니라 개발 진단 결과다.
- 576개는 72개 문장 틀의 직무 변형이다. 새 테스트는 문장 틀이 분리됐어도 같은 작성 방식과 직무 어휘를 공유하므로 실제 계약서 일반화 성능을 보여주지 않는다.
- PDF 478건은 반복 문구가 많고 정답은 법률 전문가 검수 전이다. 전체 정확 일치 468/478만으로 운영 품질을 판단하지 않는다.
- 멀티라벨 보강의 다음 검증에는 다른 작성자·양식의 실제형 조항과 검수된 단일·멀티라벨 정답이 필요하다. 특히 단일 라벨 오탐을 함께 확인해야 한다.
